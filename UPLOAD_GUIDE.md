# Bhaskar Stationery Shop — Colorful Upload Package

1. Download and extract this ZIP.
2. Upload ALL files to your GitHub repository (do not upload only index.html).
3. Keep index.html and style.css in the same folder.
4. Enable GitHub Pages from Settings > Pages > Deploy from branch > main > /root.
5. Open the generated public URL.
6. For Google Search, add the public URL to Google Search Console and submit its sitemap after replacing YOUR-DOMAIN.example with the real URL.

The colorful design is mobile-friendly and bilingual. The current admin is a demo front-end; a real public shop should use secure server-side authentication and a shared database.
